# Personalized Music Streaming App

## Overview
A Spotify-style web application where users can browse and play tracks while receiving personalized recommendations based on simple preference filters.  
Built with **React (Vite)** and **Tailwind CSS** for a fast, responsive, and modern user interface.

---

## Features
- **Track Browsing** — Explore a curated library of songs.
- **Personalized Recommendations** — Uses filtering logic to tailor suggestions to user preferences.
- **Playlist Management** — Create and organize playlists.
- **Responsive Design** — Works seamlessly on desktop and mobile.
- **Playback Controls** — Play, pause, and skip tracks in real time.

---

## Technologies Used
- **Frontend:** React.js (Vite), Tailwind CSS, PostCSS
- **Tooling:** Node.js, npm
- **Concepts:** Component-based architecture, React hooks, state management, dynamic filtering

## Getting Started
```bash
# 1. Clone the Repository
git clone https://github.com/mmakei/project-music-app.git
cd project-music-app

# 2. Install Dependencies
npm install

# 3. Run the Development Server
npm run dev

# 4. Build for Production
npm run build

# 5. Preview the Production Build
